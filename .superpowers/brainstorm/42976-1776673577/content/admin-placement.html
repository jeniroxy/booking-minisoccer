Di mana UI "Jadwal Tetap" ditempatkan?

Pilih salah satu pendekatan layout di admin

A

Tab baru di halaman Booking

Tambah tab "Jadwal Tetap" sejajar dengan Pending / Akan Main / Selesai / Cancelled. Semua booking management di satu halaman.

Admin — Booking
Pending Akan Main Selesai Cancelled ✦ Jadwal Tetap
Daftar jadwal tetap + tombol + Add
B

Section terpisah di bawah tabel booking

Scroll ke bawah di halaman admin untuk lihat section Jadwal Tetap. Sederhana tapi panjang.

Admin — Booking
📋 Tabel booking (Pending / Akan Main / ...)
⬇ Jadwal Tetap
Daftar jadwal + Add
C

Halaman admin terpisah

Route /admin/jadwal-tetap sendiri. Navigasi via sidebar/link. Paling rapi untuk skala besar tapi butuh effort lebih.

Admin — Jadwal Tetap
← Booking | Jadwal Tetap
Halaman full untuk manage recurring schedules
